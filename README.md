# 🌐 Personal Portfolio Website with CI/CD Integration

A clean and interactive **Portfolio Website** built using **HTML**, **CSS**, and **Vanilla JavaScript** to showcase my projects, skills, and contact information. This portfolio serves as a digital resume and highlights my frontend development capabilities using core web technologies.

## 🔁 CI/CD Pipeline with Jenkins

This project is integrated with a **CI/CD pipeline** using **Jenkins**:

- GitHub webhooks trigger a Jenkins job on every push to the `main` branch.
- The latest code is automatically built and deployed to a local web server.
- No Docker is used — deployment is handled with a Jenkins-managed batch script on **Windows**.
- This setup reduces manual steps and ensures automatic delivery of updates.

## 🛠️ Technologies Used

- **HTML5** – Page structure and content
- **CSS3** – Styling and responsive design
- **JavaScript (Vanilla)** – Interactivity and DOM manipulation
